## WHAT WE ARE BUILDING
A real government bus ticketing and AI revenue recovery system
for Tamil Nadu State Transport Corporation (TNSTC).

This is NOT a startup product. NOT a SaaS dashboard.
This is a GOVERNMENT OPERATIONS TOOL used by:
- Bus conductors (on moving buses, one hand, bright sunlight)
- Transport department admins (desktop, data-heavy analysis)
- Passengers (mobile, no login, one-tap payment retry)

The UI must feel like it was built by a senior frontend engineer
at a company like Razorpay or Swiggy — not generated by AI.
Opinionated design decisions. Real hierarchy. Purposeful use of color.
Nothing decorative that doesn't serve a function.

---

## DESIGN PHILOSOPHY — READ THIS FIRST

### The three screens have completely different users:

CONDUCTOR (Moving bus, phone, outdoor sunlight):
- One hand operation always
- Large touch targets minimum 48px
- High contrast — readable in direct sunlight
- Minimal cognitive load — conductor is also managing passengers
- Critical information first — amount, status, route
- Dark mode preferred — reduces eye strain on long shifts

ADMIN DASHBOARD (Office desktop, data analysis):
- Information density matters — admin needs everything at once
- Data tables, charts, metrics — professional and clean
- Light mode — standard office environment
- Sidebar navigation — multiple sections
- Recharts graphs — styled consistently, not default colors

PASSENGER RETRY PAGE (WhatsApp link tap, any phone):
- Arrives from a WhatsApp/SMS message
- No login, no signup, no friction
- One goal: pay now
- Mobile only
- Trust signals important — government branding

## WHAT NOT TO DO — STRICT RULES

❌ No glassmorphism on admin dashboard (only conductor dark UI)
❌ No gradient backgrounds on admin screens
❌ No decorative illustrations that don't serve data
❌ No centered hero sections on dashboard
❌ No stock photo style backgrounds
❌ No neon colors or glow effects
❌ No rounded corners above 20px on desktop cards
❌ No animation on data — only on status indicators
❌ No emoji in admin dashboard UI (conductor UI only)
❌ No card shadows heavier than 0 4px 12px rgba(0,0,0,0.08)
❌ No font sizes below 11px
❌ No color as the only differentiator (always pair with icon/text)
❌ Do not center-align table content (left align everything except amounts)
❌ No more than 3 primary actions visible at once on any screen
